Reference code A6005008

Reference codeA6005008
FamilyA6xx - partition attention, operating system waiting
Words 2-900000002 00000000 00000000 00000000 00000000 00000000 00000000 00000000
Reported byQSTEST01 (ID 2) on QSHQVS1, 10/29/26 23:30:44
SeverityAttention - IPL is waiting, no hardware fault

Meaning

The partition reached the point in a manual (keylock Manual, attended) IPL where it presents the dedicated service tools or the sign-on display on its console, and no console device is connected. Word 2 is the partition ID.

Cause

The console is a terminal window through the virtual serial adapter and no QS/MC session has opened one, or the previous session disconnected (QMC4001). This also appears when the console device in the partition settings does not match the adapter the operating system found.

Recovery

Open a terminal window on the partition (Operations > Open terminal window). The IPL continues as soon as the console connects. If the code remains after the console is connected, select control panel function 21 to force DST to the console, then check the console device setting under Settings.
